# ❤️ С Днём рождения, мама

## Цифровой подарок от сердца

Этот проект — не просто сайт. Это маленькая история любви, благодарности и семейных воспоминаний, созданная специально для самого родного человека.

## ✨ Возможности

- премиальный праздничный дизайн
- красивые плавные анимации
- интерактивные частицы и сердечки
- семейная фотогалерея
- полноэкранный просмотр фотографий
- адаптивность для телефонов и планшетов
- эмоциональные секции поздравления
- эффекты свечения и переходов

## 🛠 Технологии

- HTML5
- CSS3
- JavaScript
- CSS animations
- GitHub Pages

## 🚀 Запуск

Откройте `index.html` в браузере или используйте GitHub Pages.
