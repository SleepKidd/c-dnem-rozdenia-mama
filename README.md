## О проекте

Это не обычный лендинг, а интерактивная семейная открытка. Сайт постепенно раскрывается как подарок: от анимированного вступления и большого личного письма до семейного альбома, важных воспоминаний и финального признания в любви.

**Открыть сайт:** [sleepkidd.github.io/c-dnem-rozdenia-mama](https://sleepkidd.github.io/c-dnem-rozdenia-mama/)

## Возможности

- праздничное вступление с анимированным подарком;
- большое личное поздравление в формате письма;
- 12 отдельных тёплых пожеланий;
- 5 настоящих семейных фотографий без заглушек;
- адаптивный фотоальбом и полноэкранный просмотр;
- навигация по галерее кнопками, клавишами и свайпами;
- временная линия семейных воспоминаний;
- частицы, лепестки, свет, параллакс и плавные появления;
- интерактивный финал с «миллионом сердечек»;
- корректная работа на телефонах, планшетах и компьютерах;
- поддержка `prefers-reduced-motion` для комфортного просмотра;
- семантичная разметка, клавиатурная навигация и доступные подписи;
- автоматическая проверка файлов перед публикацией.

## Технологии

- **HTML5** — семантичная структура и метаданные;
- **CSS3** — адаптивная сетка, эффекты и анимации без фреймворков;
- **Vanilla JavaScript** — галерея, частицы, параллакс и интерактив;
- **WebP** — оптимизированные полноразмерные фото и миниатюры;
- **GitHub Actions + GitHub Pages** — автоматическая проверка и публикация.

В проекте нет сторонних библиотек, сборщиков и внешних шрифтов. Поэтому он быстро открывается и не зависит от CDN.

## Локальный запуск

Самый простой вариант — открыть `index.html` в браузере.

Для запуска через локальный сервер:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Проверка проекта

Нужен Node.js 18 или новее. Устанавливать зависимости не требуется.

```bash
npm test
```

Проверка находит отсутствующие локальные ресурсы, пустые изображения, повторяющиеся `id` и изображения без `alt`.

## Публикация

GitHub Pages уже настроен на публикацию корня ветки `main`. Отдельный workflow `.github/workflows/quality.yml` запускает проверку при каждом push и pull request. Все пути относительные, поэтому сайт корректно работает внутри пути репозитория `/c-dnem-rozdenia-mama/`.

Фотографии в каталоге `images/` являются личными семейными материалами и не предназначены для повторного использования.
